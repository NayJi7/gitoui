## What is <span class="gitoui-wordmark"><span class="git-part">git</span><span class="oui-part">oui</span></span>?

**<span class="gitoui-wordmark"><span class="git-part">git</span><span class="oui-part">oui</span></span>** is a fork of [serie](https://github.com/lusingander/serie) that goes
beyond the commit-graph viewer. The original focus — a rich
`git log --graph` rendered with terminal image protocols — is intact; on top of
it <span class="gitoui-wordmark"><span class="git-part">git</span><span class="oui-part">oui</span></span> adds a full TUI workflow for everyday git: diffs, blame, staging,
interactive rebase, conflict resolution, and GitHub integration for PRs and
Issues.

It runs the `git` CLI directly (no libgit2 binding) and pre-renders the commit
graph as SVG/PNG images displayed inline in your terminal.
